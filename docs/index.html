A Dynamic Island for MangoWC

One black pill replaces Waybar. Hover it for workspaces, media, stats and the tray, drag it out of the way, and it floats over your windows without moving them.

That pill at the top is a working copy. Open it and pick a workspace: this page's wallpaper changes, and so does the accent, the way the real one follows yours.

Measured in a private headless Mango against a real daily-driver Waybar config: workspace pills, media, audio, tray, network and clock. The island's numbers include its pactl listener. Waybar's switch cost includes the helper commands its custom workspace modules run, but not the separate script that feeds them. Treat idle as a tie: both sit near zero, and Waybar moves with audio server activity. Waybar has the smaller binary. Run bench/run.py to reproduce this.

Change anything

Most changes take a line of config. When they don't, a new module is one file.

Rearrange it

The pill and panel are ordered lists of modules. Reload without restarting.

pill = ["workspaces", "clock"]
panel = ["header", "media", "audio"]

Add a module with a script

Any shell command works. Its output is the module.

[[custom]]
name = "weather"
exec = "curl -s 'wttr.in/?format=%t'"
interval = 600

Write one in Rust

A module is one function that draws and returns where it ended.

pub fn pill(p: &mut Pen, c: &Ctx, x: f64) -> f64 {
    x + p.text("hi", 13.0, Weight::Bold,
               p.pal.fg, x, 16.0, -1.0)
}

Port it to your compositor

Compositor support sits behind a five-method trait, so a port is one file.

trait Backend {
    fn watch(&self, tx: Tx);
    fn view(&self, tag: u32, monitor: &str);
    // send_to, focus, cycle
}

Install it

Run this inside a Mango session. It keeps your originals, and --undo puts Waybar back.

git clone https://github.com/nurexa/Rust-Dynamic-Island-for-Mango
cd Rust-Dynamic-Island-for-Mango
./install.sh

You'll need Rust, cairo, pango, a Nerd Font, adwaita-icon-theme, and playerctl for media. The island replaces Waybar's tray watcher too, so your tray apps keep working.

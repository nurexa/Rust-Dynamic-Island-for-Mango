Your whole desktop in one pill

A minimal, modular, all-in-one tool for MangoWC. One small Rust program is your bar, app search, sidebar, notifications, clipboard and screenshots, in seven styles from a floating pill to a frame around your screen. Use all of it, or only the parts you want.

That pill at the top is the real one, ported to your browser with made-up stats. Hover it to open the panel, then press the wallpaper button: this page's wallpaper changes, and the accent follows, the way the real one follows yours. Drag it anywhere, double-click it to send it home.

With the pointer on the pill, try the keys it has on the desktop (there with Super): Space search, D apps, R run, C clipboard, S screenshot, W wallpapers, M power, I pin, N a test notification. In search, Tab switches tools and Esc closes.

Measured 2026-11-22 in a private headless Mango: Waybar 0.16.0 with its stock config and the island with its defaults, each started fresh with the order rotated between runs. Child processes count. Stock Waybar has no module for Mango's workspaces, so it has no switch cost to compare. Absolute memory moves between sessions: the island's Nov 2 build read 12.5 MB beside mangobar that day and 14.8 MB in this session, so everything added since costs 0.4 MB. The six styles rest between 12.9 and 14.8 MB. While music plays the visualizers cost 0.6% of a core on the pill and up to 1.6% in the panel or sidebar, and nothing measurable when it's paused. A busy desktop moves all of these, so run bench/run.py on yours.

Change anything

Most changes take a line of config. When they don't, a new tool or module is one file.

Keep only what you want

Everything is an ordered list. Reload without restarting.

pill = ["workspaces", "clock"]
tools = ["apps", "clipboard"]
notifications = false

Add a tool with a script

Two shell commands make a searchable tool.

[[tool]]
name = "projects"
list = "ls ~/Projects"
run = "kitty -d ~/Projects/{}"

Build only what you need

Compile parts out for a smaller binary, or write your own in one file.

cargo build --release \
  --no-default-features \
  --features "apps,clipboard"

Port it to your compositor

Compositor support sits behind a six-method trait, so a port is one file.

trait Backend {
    fn watch(&self, tx: Tx);
    fn view(&self, tag: u32, monitor: &str);
    // send_to, focus, cycle, quit
}

Install it

Run this inside a Mango session. Your keys stay the same and only what they open changes. --undo restores your config exactly.

git clone https://github.com/nurexa/Rust-Dynamic-Island-for-Mango
cd Rust-Dynamic-Island-for-Mango
./install.sh

Or paru -S rust-dynamic-island-git on Arch, or nix profile install github:nurexa/Rust-Dynamic-Island, then run /usr/share/island/install.sh (on Nix, ~/.nix-profile/share/island/install.sh). Afterwards, island doctor says what works on your machine.

You'll need Rust, cairo, pango, libxkbcommon, a Nerd Font, playerctl for media, and parec for the visualizers. The icons are built in. Pick a look as you install with ./install.sh --style=frame. Want to pick each part and key yourself? Use ./install.sh --manual. Only the bar? ./install.sh --bar-only. Works with config.conf and config.toml, and keys you already use stay yours.

Your whole desktop in one pill

A minimal, modular, all-in-one tool for MangoWC. One small Rust program is your bar, app search, sidebar, notifications, clipboard and screenshots, in seven styles from a floating pill to a frame around your screen. Use all of it, or only the parts you want.

That pill at the top is the real one, ported to your browser with made-up stats. Hover it to open the panel (in the real one, a grid of tiles: a big clock, calendar, CPU, GPU and RAM meters, system info, media, pomodoro, levels, connections, and weather if you opt in, from open-meteo with no key; this demo keeps the older single-column panel), then press the wallpaper button: this page's wallpaper changes, and the accent follows, the way the real one follows yours. Drag it anywhere, double-click it to send it home.

With the pointer on the pill, try the keys it has on the desktop (there with Super): Space search, D apps, R run, C clipboard, S screenshot, W wallpapers, M power, I pin, N a test notification. In search, Tab switches tools and Esc closes.

Seven shapes, one island

Switch live with island style frame, or set it in the config. Only frame, bar and glass take any space from your windows.

Frame

A border with a slim rail. The island, search and sidebar grow out of it.

Pill

The default. Floats, and drags anywhere.

Notch

Hangs from the top edge.

Bar

Full width, and swells down into the panel.

Glass

A see-through floating bar in three groups, with real compositor blur on Mango (set blur_layer, cheap with blur_optimized).

Split

Music, timers and Claude bud off into a bubble.

Minimal

The time, and whatever needs you.

Measured 2026-11-22 in a private headless Mango: Waybar 0.16.0 with its stock config and the island with its defaults, each started fresh with the order rotated between runs. Child processes count. Stock Waybar has no module for Mango's workspaces, so it has no switch cost to compare. Absolute numbers move between sessions, so compare within one: the previous build, without glass, settings and scale, read 12.5 MB in the same rotation as this one. The seven styles rest between 10.6 and 12.6 MB and the light setup at 11.5 MB; blur is work Mango does on the GPU and is not counted. While music plays the visualizers cost 0.9% of a core on the pill and up to 3% in the panel or sidebar, and 0.01% when it is paused. A busy desktop moves all of these, so run bench/run.py on yours.

Change anything

Settings has a control for everything in the config and keeps your comments. For more, a new tool or module is one file.

Keep only what you want

Everything is an ordered list. Reload without restarting.

pill = ["workspaces", "clock"]
tools = ["apps", "clipboard"]
notifications = false

Add a tool with a script

Two shell commands make a searchable tool.

[[tool]]
name = "projects"
list = "ls ~/Projects"
run = "kitty -d ~/Projects/{}"

Build only what you need

Compile parts out for a smaller binary, or write your own in one file.

cargo build --release \
  --no-default-features \
  --features "apps,clipboard"

Port it to your compositor

Compositor support sits behind a six-method trait, so a port is one file.

trait Backend {
    fn watch(&self, tx: Tx);
    fn view(&self, tag: u32, monitor: &str);
    // send_to, focus, cycle, quit
}

Install it

Run this inside a Mango session. Your keys stay the same and only what they open changes. --undo restores your config exactly.

git clone https://github.com/nurexa/Rust-Dynamic-Island-for-Mango
cd Rust-Dynamic-Island-for-Mango
./install.sh

Or paru -S rust-dynamic-island-git on Arch, or nix profile install github:nurexa/Rust-Dynamic-Island, then run /usr/share/island/install.sh (on Nix, ~/.nix-profile/share/island/install.sh). Afterwards, island doctor says what works on your machine.

You'll need Rust, cairo, pango, libxkbcommon, a Nerd Font, playerctl for media, and parec for the visualizers. The icons are built in. Pick a look as you install with ./install.sh --style=frame (--style=glass --blur for blur), or start small with ./install.sh --light. Want to pick each part and key yourself? Use ./install.sh --manual. Only the bar? ./install.sh --bar-only. Works with config.conf and config.toml, and keys you already use stay yours.

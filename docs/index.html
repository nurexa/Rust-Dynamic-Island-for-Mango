Your whole desktop in one pill

A minimal, modular, all-in-one tool for MangoWC. One small Rust program is your bar, app search, notifications, clipboard and screenshots. Use all of it, or only the parts you want.

That pill at the top is a working copy. Open it and pick a workspace: this page's wallpaper changes, and so does the accent, the way the real one follows yours.

Measured in a private headless Mango: Waybar 0.15.0 with a daily-driver config (workspace pills, media, audio, tray, network, clock), mangobar 0.2.2 with its stock config, and the island with its defaults, each started fresh with the order rotated between runs. Child processes count, including the island's pactl listener. Waybar's switch cost includes the helper commands its custom workspace modules run, but not the separate script that feeds them. mangobar is the faster of the two small bars at redrawing a workspace change and has by far the smallest binary, but the island uses less memory and wakes up a third as often while also replacing your launcher, notifications and clipboard. An earlier run against Waybar plus dunst and rofi put the island's launcher at 8 ms against rofi's 41 ms. A busy desktop moves all of these, so run bench/run.py on yours.

Change anything

Most changes take a line of config. When they don't, a new tool or module is one file.

Keep only what you want

Everything is an ordered list. Reload without restarting.

pill = ["workspaces", "clock"]
tools = ["apps", "clipboard"]
notifications = false

Add a tool with a script

Two shell commands make a searchable tool.

[[tool]]
name = "projects"
list = "ls ~/Projects"
run = "kitty -d ~/Projects/{}"

Build only what you need

Compile parts out for a smaller binary, or write your own in one file.

cargo build --release \
  --no-default-features \
  --features "apps,clipboard"

Port it to your compositor

Compositor support sits behind a six-method trait, so a port is one file.

trait Backend {
    fn watch(&self, tx: Tx);
    fn view(&self, tag: u32, monitor: &str);
    // send_to, focus, cycle, quit
}

Install it

Run this inside a Mango session. Your keys stay the same and only what they open changes. --undo restores your config exactly.

git clone https://github.com/nurexa/Rust-Dynamic-Island-for-Mango
cd Rust-Dynamic-Island-for-Mango
./install.sh

You'll need Rust, cairo, pango, libxkbcommon, a Nerd Font, adwaita-icon-theme, and playerctl for media. Prefer only the bar? Use ./install.sh --bar-only.
